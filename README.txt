PEEYUSH KUMAR JANGID — PORTFOLIO WEBSITE

FILES
- index.html : website structure and content
- style.css  : Premium Dark Blue responsive design
- script.js  : mobile menu, scroll reveal and skill bar animations
- assets/    : put your resume and project photographs here

BEFORE PUBLISHING
1. Keep your existing PDF resume in the repository root:
   Peeyush_Kumar_Jangid_Resume.pdf
   The Download CV button points to this exact path. The current live site already uses this PDF filename.
2. Replace the three illustrative project images in index.html with your own site photographs if available.
3. Review the skill percentages in index.html. They are illustrative self-assessment values, not verified test scores.
4. Confirm your education, experience dates, phone, email and LinkedIn URL are still correct.

LOCAL PREVIEW
- Extract the ZIP.
- Open index.html in Chrome, Safari or Edge.

PUBLISH TO YOUR EXISTING GITHUB PAGES SITE
1. Open your GitHub repository for peeyush-jangid.github.io.
2. Back up/download the current repository first.
3. Upload index.html, style.css, script.js and the assets folder to the repository root.
4. Keep the repository's existing Pages publishing branch/folder setting unchanged.
5. Commit the changes and wait for GitHub Pages to publish.
6. Open https://peeyush-jangid.github.io and hard-refresh the page.

NOTES
- This is a static HTML/CSS/JS site; no build tools or paid hosting are required.
- Google Fonts and the sample project photos load from the internet. Replace sample photos with real project images for a stronger portfolio.
- The current published resume URL was identified as a PDF. Add a copy of that PDF to the assets folder using the filename above.

PRIVATE EXCEL & WORD UPLOAD MANAGER
- Upload admin.html, admin.css, admin.js and work-files.js with the updated index.html and style.css.
- Open https://peeyush-jangid.github.io/admin.html to manage work samples.
- Create a GitHub fine-grained personal access token for ONLY this repository, with Contents: Read and write permission and a short expiry. Never commit or share the token.
- Paste the token in the admin page when uploading. It is held in page memory only, not localStorage.
- Files are committed to documents/ and listed automatically in the public Work Showcase.
- GitHub Pages is static: GitHub repository permissions provide the upload gate. Keep the token private and revoke it when no longer needed. Published documents are public; do not upload confidential files.
- Max upload size: 8 MB per file.
